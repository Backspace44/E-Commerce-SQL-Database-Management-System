# E-Commerce-SQL-Database-Management-System
Database project developed as part of a DBMS course, covering relational database design, ER modeling, SQL implementation, and technical documentation. The repository is organized for clear presentation and portfolio use.

## Project Scope

- Conceptual and logical data modeling
- Relational database design
- SQL schema implementation and queries
- Requirements and technical documentation

## Repository Structure

- `Documentatie/` - requirements and supporting documentation
- `Diagrame/` - ER diagram source and preview
- `Capturi/` - screenshots demonstrating the SQL requirements
- `Livrabile/` - final SQL script, project document, and presentation

## Skills Demonstrated

- Relational database design and normalization
- Constraints and data integrity
- SQL schema creation, data manipulation, views, and complex queries
- ER diagramming
- Technical project documentation
